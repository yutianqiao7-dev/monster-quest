# モンスタークエスト

スマホのブラウザで遊べる、オリジナルのモンスター収集RPG。
外部ライブラリなし・1ファイル完結（`index.html`）。

**▶ 遊ぶ: https://yutianqiao7-dev.github.io/monster-quest/**

## 特徴

- **16種のモンスター** — 16×16のドット絵を手描き。御三家3体は Lv16 で進化
- **8タイプの相性** — ばつぐん／いまひとつ／こうかなし
- **戦闘** — 素早さと優先度による行動順、急所、命中判定、どく・まひ・ねむり、能力up/down、30種の技とPP管理
- **育成** — 経験値、レベルアップ、技習得（5つ目は忘れる技を選択）、進化演出
- **捕獲** — 残りHP・状態異常・ボール性能で確率が変動、3段階の揺れ演出
- **マップ** — ハジマリの町／ルート1／トキワのもり。草むらでのランダムエンカウントとマップ間移動
- **その他** — トレーナー戦、ライバル戦、ショップ、回復、図鑑、手持ち入替とボックス、全滅処理、`localStorage` へのセーブ

## 操作

| | スマホ | キーボード |
|---|---|---|
| 移動 | 十字キー | カーソルキー / WASD |
| 決定 | A | Z / Enter |
| キャンセル | B | X / Esc |
| メニュー | START | Shift |

効果音は画面右下のボタンでOFFにできます。

## 進め方

町を出て北へ向かうには、研究所が道を塞いでいるので東側から回り込みます。
目標はトキワのもり最奥のライバル・ケイ。手持ちが Lv15 前後ないと厳しいので、
ルート1の草むらで育ててから挑んでください。

## 技術メモ

- 160×144 の論理解像度をオフスクリーンcanvasに描き、整数倍で拡大して表示
- テキストのみ表示解像度で描画するため、ドット絵はカリカリのまま日本語が読める
- 戦闘やイベントは async/await で記述し、`await say(...)` / `await choose(...)` が入力待ちを兼ねる
