# モンスタークエスト

スマホのブラウザで遊べる、オリジナルのモンスター収集RPG。
外部ライブラリなし・1ファイル完結（`index.html`）。

**▶ 遊ぶ: https://yutianqiao7-dev.github.io/monster-quest/**

## 特徴

- **138種のモンスター** — 16×16のドット絵。45系統が進化する（3段階に育つ系統が7つ）
- **6体の伝説のモンスター** — それぞれ専用の祭壇にいる。捕獲か撃破で二度と現れない
- **8つのジム** — それぞれ専用の建物と仕掛けがあり、解かないとリーダーに会えない
- **四天王とチャンピオン** — 8バッジを集めるとリーグへ。5連戦は途中で回復できない
- **73のマップ** — 9つの町、25軒の家、8つのジム内部、9本の道、森、洞窟、火山、リーグ6部屋、伝説の祭壇6室、外洋と3つの島
- **町の家に入れる** — すべての扉が開く。住人と話せて、町ごとに道具をくれる人がいる
- **つり** — つりざおで水辺からみずタイプを釣り上げる。場所ごとに釣れる種類が違う
- **落ちている道具** — 道や洞窟に18個。一度拾うと消える
- **ゲームコーナー** — テンボウ台のスロット。コインを貯めて景品やモンスターと交換
- **ひでんマシン4種** — いあいぎり／なみのり／かいりき／そらをとぶ
- **水上限定モンスター5種** — なみのりでしか出会えない。草むらには絶対に出ない
- **殿堂入り後の追加要素** — はての島、バトルタワー、四天王とチャンピオンの再戦、島だけの6種
- **15タイプの相性** — ばつぐん／いまひとつ／こうかなし（相性表を見られるNPCもいる）
- **新7タイプは各8種** — こおり・ドラゴン・ゴースト・あく・はがね・かくとう・エスパー
- **複合タイプ30種** — タイプを2つ持つ。相性がかけ算になり、4倍や4分の1が出る
- **戦闘** — 素早さと優先度による行動順、急所、命中判定、どく・まひ・ねむり、能力up/down、**152種の技**とPP管理
- **技の仕掛け** — 連続ヒット・吸収・反動・急所率アップ・先制・必中
- **育成** — 経験値、レベルアップ、技習得（5つ目は忘れる技を選択）、進化演出
- **BGM12曲** — 場面で自動的に切り替わる。戦闘曲は相手の格ごとに別の曲
  （野生／トレーナー／ジムリーダー／四天王／チャンピオン／伝説）
- **攻撃演出** — **152種の技すべてに専用のエフェクト**。同じ見た目の技はひとつもない。効果音は15タイプそれぞれ
- **捕獲** — 残りHP・状態異常・ボール性能で確率が変動、3段階の揺れ演出
- **15種の道具** — ボール3種、回復薬、状態異常の個別治療、PP回復、ふしぎなアメ、つりざお
- **つうしん対戦** — 友達の端末と対戦できる。チームコード方式とP2Pリアルタイム方式の2つ
- **セーブデータ3つ** — タイトルで選ぶ。3人で1台を共有しても混ざらない
- **その他** — トレーナー戦22人、2度戦うライバル、ショップ、回復、図鑑、手持ち入替とボックス、全滅処理、`localStorage` へのセーブ

## ひでんマシン

町の「ひでんの けんきゅうか」からもらえます。**その わざに合ったタイプのモンスターを
てもちに入れていないと使えません。** メニューの「ひでんわざ」で誰が使えるか確認できます。

| わざ | もらえる町 | 必要なタイプ | できること |
|---|---|---|---|
| **いあいぎり** | セイリュウシティ | くさ・むし | ちいさな木を切って近道を開く |
| **なみのり** | ヒナタ港町 | みず | 水の上を進める。水上でも釣りができる |
| **かいりき** | ガンセキ村 | いわ・ノーマル | 野外の大岩を押してどかす |
| **そらをとぶ** | ソラミ台 | ひこう | **一度行った町へ一瞬で移動** |

**そらをとぶ**はメニュー →「ひでんわざ」から。訪れたことのある町だけが行き先に並びます。
洞窟や建物の中からは飛べません。

**なみのり**は水辺に向かって A。釣りざおも持っていればどちらを使うか選べます。
陸に上がると自動でおります。水上では約7%で野生のみずタイプが出ます。

小さな木はルート2・5・9に、大岩はチャンピオンロードにあります。
どれも本筋を塞いではいないので、持っていなくても詰みません。

## うみへ出る

**なみのり**を手に入れたら、**ヒナタ港町の東の海**から外洋へ出られます。

そとうみには道具を置いた小島が2つ、中央の島にふなのりのトレーナーがいます。
さらに東の端まで渡ると **こじま** に着きます。ここの砂浜は海の主 **リュウグウジ** の住みかです。

水の上では約7%で野生が出ますが、**出てくる種類は陸とはまったく別**です。

| 水上限定モンスター | 特徴 |
|---|---|
| **クラゲット** | 序盤から出る。守りが高い |
| **サメジャ** | 攻撃とすばやさが高い狩人 |
| **タツノミ** → **リュウグウジ** | Lv36で進化。海の主 |
| **シンジュヒメ** | 防御118。硬さは全種でも屈指 |

**この5種は草むらには絶対に出ません。** 釣りとも出現表が別なので、
なみのりで海に出るしか手に入れる方法がありません。

ルート1・2・7・8・ヒナタ港町の水辺にもそれぞれ専用の出現表があり、
場所が北へ行くほど強い個体が出ます。水の上にしか行けない場所に道具も3つ置いてあります。

## タイプ

**15タイプ**あります。もとの8つに加えて、こおり・ドラゴン・ゴースト・あく・はがね・
かくとう・エスパーの7つ。

| タイプ | 得意 | 苦手 |
|---|---|---|
| **こおり** | くさ・ひこう・**ドラゴン** | ほのお・かくとう・いわ・はがね |
| **ドラゴン** | ドラゴン | こおり・ドラゴン |
| **ゴースト** | エスパー・ゴースト | あく・ゴースト（**ノーマルは効かない／効かせない**） |
| **あく** | エスパー・ゴースト | かくとう・むし |
| **はがね** | いわ・こおり | ほのお・かくとう |
| **かくとう** | ノーマル・いわ・こおり・あく・はがね | ひこう・エスパー（**ゴーストには効かない**） |
| **エスパー** | かくとう | むし・あく（**あくには効かない**） |

**「こうかが ない」組み合わせでは、ダメージが 0 になります。**

もとからある8タイプ同士の相性は**一切変えていない**ので、これまでのセーブの
進み方は変わりません。

## 技

**152種**あります。15タイプそれぞれに**9〜15種**。全部どこかのモンスターが覚えます。

威力と命中の駆け引きだけでなく、こんな仕掛けがあります。

| 仕掛け | 内容 | 例 |
|---|---|---|
| **連続ヒット** | 2〜5回当たる。1発は軽いが合計は大きい | れんげき・つららばり・たねマシンガン |
| **吸収** | 与えたダメージの半分だけ回復する | きゅうけつ・たましいくい・かげぬすみ |
| **反動** | 与えたダメージの1/4〜1/3を自分も受ける | すてみアタック・きゅうこうか・たつのとっしん |
| **急所率アップ** | 4回に1回くらい急所に当たる | リーフエッジ・せいけんづき・やみのいちげき |
| **先制** | 素早さに関係なく先に動く | いしつぶて・こおりのつぶて・かげぬい |
| **必中** | 外れない代わりに威力は控えめ | でんげきは・つばめがえし・だましうち |

状態異常・能力上下・回復技も増えました。**てっぺき**は防御が2段階上がります。

### エフェクトは技ごとに別

**152種すべてが違う見た目**です。タイプで色分けした上で、
**24種類の「動き」と8種類の「粒の形」を組み合わせ**、同じ組み合わせは1つもありません。

| 動きの例 | 見た目 |
|---|---|
| なぐる・れんだ | その場で弾ける／続けざまに小さく弾ける |
| きりさき・つめあと | 斜めの斬線／3本の爪跡 |
| ふりそそぐ・わきあがる | 上から降る／下から立ちのぼる |
| ビーム・いなずま | 撃つ側からまっすぐ／上からジグザグ |
| うず・らせん | その場で渦巻く／回りながら集まる |
| すいとり | 相手から自分へ流れ込む（吸収技） |
| しょうげき | 重い一撃と衝撃波（反動技） |
| かがやき・きらきら | 自分が光る（能力上昇）／輝く（回復） |
| とばり | 暗幕が降りる（能力低下） |

技の性質に合わせて動きを選んでいるので、**見ただけで吸収技か反動技か連続技かが分かります**。

覚える技はレベルアップで自動的に増えます。**5つ目を覚えるときは忘れる技を選べます**。

## 複合タイプ

**タイプを2つ持つモンスターが30種**います。**20とおりの組み合わせ**があります。

相性は**2つぶんをかけ算**します。

| 例 | 計算 | 結果 |
|---|---|---|
| いわ技 → **ホムラバネ**（ほのお/ひこう） | 2 × 2 | **4倍** |
| くさ技 → **ホムラバネ**（ほのお/ひこう） | 0.5 × 0.5 | **4分の1** |
| ノーマル技 → **ゲンムオウ**（エスパー/ゴースト） | 1 × 0 | **0（効かない）** |
| でんき技 → **ヨクリュウ**（ひこう/ドラゴン） | 2 × 0.5 | 等倍 |

4倍のときは「**こうかは バツグンだ! とてつもなく きいた!**」、
4分の1のときは「**こうかは ほとんど ないようだ…**」と出ます。

自分のわざも、**2つのどちらかと同じタイプなら1.5倍**（タイプ一致）になります。

## 殿堂入りしたあと

チャンピオンに勝つと、ここから先が開きます。

### はての島へ

**こじまの東の海に大きなうずしお**があって、それまでは近づけません。
殿堂入りするとうずしおが静まり、なみのりで東へ渡れるようになります。

## セーブデータ

**3つまで別々に持てます。** タイトルで選んでください。

```
データを えらぶ
 データ1 モクリ Lv9        バッジ0   0:10
 データ2 バーニクス Lv44    バッジ3   3:20
 データ3 ★セカイオー Lv80   バッジ8  27:30
 データを けす
```

- 一覧には**先頭のモンスター・レベル・バッジ数・プレイ時間**が出ます。**★は殿堂入り済み**
- **あきデータを選ぶと、そのデータで新しく始まります**
- 中身のあるデータを選べば、その続きから。以降のセーブは全部そのデータに入ります
- メニューの「セーブ」も「**データ1に セーブしますか?**」と、どれに書くか出ます
- 消すときは「データを けす」→ データを選ぶ → 確認。**消したデータは戻りません**

**前のバージョンのセーブは、初回起動時に自動でデータ1へ引っ越します。** 何もしなくて大丈夫です。

## つうしん対戦

メニューの「つうしん」から。サーバーを持たないので方式は2つあります。

### チームコード たいせん

自分の手持ちを短い文字列にして友達に送ると、相手はそのチームと戦えます（相手の手指しはAI）。
リアルタイムではありませんが、**どんな回線でも確実に動き**、オフラインでも成立します。
6匹で75文字ほど。コピーはボタン一発です。

### ちょくせつ たいせん（P2P）

WebRTC で端末同士を直接つなぎ、本当に同時進行でターン制バトルをします。中継サーバーはありません。

1. 片方が「しょうたいする」を選び、出てきた招待コードをLINEなどで送る
2. もう片方が「しょうたいコードで さんか」を選んでそれを貼る
3. 出てきた返事のコードを送り返し、最初の人が貼る

コードは700文字ほどなのでコピー＆ペーストで渡してください。
判定はホスト側が行い、結果を出来事の列にして両端末で再生するため、表示がずれません。

どちらの方式も**冒険の記録には一切影響しません**。経験値・お金・バッジは動かず、
HPやPPも対戦前の状態にそのまま戻ります。

> 携帯回線の種類によってはP2Pがつながらないことがあります。その場合はチームコード対戦を使ってください。
> また Claude の Artifact 版では外部接続が制限されるため、P2PはGitHub Pages版でお使いください。

## 技術メモ

- 160×144 の論理解像度をオフスクリーンcanvasに描き、整数倍で拡大して表示
- テキストのみ表示解像度で描画するため、ドット絵はカリカリのまま日本語が読める
- 戦闘やイベントは async/await で記述し、`await say(...)` / `await choose(...)` が入力待ちを兼ねる
- 音は全て Web Audio による合成。音源ファイルを持たない。BGMは
  8分音符32ステップのパターンを先読みスケジューリングで鳴らす簡易シーケンサ
- 戦闘曲は相手の種類から自動で選ぶ。トレーナー側で bgm を指定もできる
- 家の内部マップは扉の数だけ実行時に自動生成して登録している。
  手書きの部屋を増やさずに「どの扉からも入れる」を実現している
- チームコードは独自のBase32（紛らわしい 0O1I を除外）＋チェックサム
- P2Pの接続コードは SDP を deflate-raw で圧縮してBase64化（約2.5KB→700字）
