# モンスタークエスト

スマホのブラウザで遊べる、オリジナルのモンスター収集RPG。
外部ライブラリなし・1ファイル完結（`index.html`）。

**▶ 遊ぶ: https://yutianqiao7-dev.github.io/monster-quest/**

## 特徴

- **22種のモンスター** — 16×16のドット絵を手描き。9系統が進化する
- **6つのジム** — それぞれ専用の建物と仕掛けがあり、解かないとリーダーに会えない
- **23のマップ** — 7つの町、6つのジム内部、7本の道、森、洞窟、火山
- **8タイプの相性** — ばつぐん／いまひとつ／こうかなし
- **戦闘** — 素早さと優先度による行動順、急所、命中判定、どく・まひ・ねむり、能力up/down、30種の技とPP管理
- **育成** — 経験値、レベルアップ、技習得（5つ目は忘れる技を選択）、進化演出
- **BGM8曲** — 町・街・道・森・洞窟・野生戦・トレーナー戦・タイトル。場面で自動的に切り替わる
- **攻撃演出** — 8タイプそれぞれ専用のエフェクトと効果音（炎・水しぶき・葉の斬撃・落雷・落石・弾幕・風・衝撃）
- **捕獲** — 残りHP・状態異常・ボール性能で確率が変動、3段階の揺れ演出
- **その他** — トレーナー戦22人、2度戦うライバル、ショップ、回復、図鑑、手持ち入替とボックス、全滅処理、`localStorage` へのセーブ

## ジムの仕掛け

町のジムの扉から中に入ります。それぞれ違う仕掛けを解かないと奥のリーダーに会えません。

| ジム | 仕掛け |
|---|---|
| セイリュウ（むし） | いけがきの迷路。一本道の要所に立つトレーナー3人を倒して進む |
| ヒナタ（みず） | 床のスイッチを踏むと水門が開く。2枚の門を順に開ける |
| テンボウ（でんき） | 電流の扉が3枚。対応する色のスイッチを順番に踏む |
| ガンセキ（いわ） | 通路を塞ぐ大岩を横から押してどかす（3個） |
| カザン（ほのお） | 溶岩のあいだの細い道をたどる。引き返せない一本道 |
| ミドリ（くさ） | 迷路の中のトレーナー3人を全員倒すと最奥の扉が開く |

スイッチはもう一度踏むと閉じ、岩は部屋を出入りすると元の位置に戻ります。

## 進め方

町を出て北へ向かうには、研究所が道を塞いでいるので東側から回り込みます。
最初の関門はトキワのもり北口のライバル・ケイ。手持ちが Lv15 前後ないと厳しいので、
ルート1の草むらで育ててから挑んでください。

そこから先はジムを順に攻略していきます。バッジを取ると次のエリアへの門が開きます。

## 技術メモ

- 160×144 の論理解像度をオフスクリーンcanvasに描き、整数倍で拡大して表示
- テキストのみ表示解像度で描画するため、ドット絵はカリカリのまま日本語が読める
- 戦闘やイベントは async/await で記述し、`await say(...)` / `await choose(...)` が入力待ちを兼ねる
- 音は全て Web Audio による合成。音源ファイルを持たない。BGMは
  8分音符32ステップのパターンを先読みスケジューリングで鳴らす簡易シーケンサ
